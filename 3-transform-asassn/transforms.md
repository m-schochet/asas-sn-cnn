## The files in this folder are structured a bit differently to the previous job files

### In specific, the jobs in this folder are structured as a single running job, such that the .sh file activating a certain .py script will run that .py script in one go rather than making references to earlier defined functions in the file and iterating through the steps

### One key difference then is that these files do not contain docstrings definitions. If there is confusion, please reach out to the authors.
