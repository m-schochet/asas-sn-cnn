## This folder hosts all associated files for plots or conclusions from Schochet et al. that are not hosted at the paper's Zenodo (10.5281/zenodo.15848602). 

### This includes:

#### tesslcs (folder): inside this folder are .fits files that hold the TESS light curves for the phase folded light curve plot in Schochet et al.
#### sim900184 (.fits): a butterpy simulation file to create the 4 stacked plot light curves showing injection from Schochet et al. (the sim900184info.txt file contains info on this simulation)
#### dr3dr2.vot (.vot): a VOTable file that contains a crossmatch between Gaia DR2 and Gaia DR3 IDs specifically for those ASAS-SN stars that our network predicted to be "good" in any of the 4 different sized networks (re: 'error' less than 3 days)
#### crossmatchedtic-kic-gaia.csv (.csv): a csv file that contains a crossmatch between Gaia DR2-KIC-TIC IDs (same as dr3dr2.vot in that it only matches to objects that were "good" predictions in either of our 4 networks)
